# Assignment #5 — JavaScript Basics (DOM Manipulation & Events)

**Student:** Nurzhan Bakirov  
**Group:** SE-2524  
**Course:** Web Technology (Front-End)  
**University:** Astana IT University

This project demonstrates JavaScript variables and operators, DOM manipulation, mouse/keyboard events, a calculator and a small interactive to-do app.

## Pages

- **Task 0:** First Script — `console.log()` and an alert
- **Task 1:** Variables & Operators — string, number, boolean, arithmetic, concatenation
- **Task 2:** Changing Content — update paragraph text
- **Task 3:** Changing Styles — background color and font size
- **Task 4:** Creating & Removing Elements — add/remove list items
- **Task 5:** Mouse Events — `mouseover` and `mouseout`
- **Task 6:** Keyboard Events — live output via `keyup`
- **Task 7:** Calculator — addition, subtraction, multiplication, division
- **Task 8:** To-Do App — add, complete and delete tasks stored in a temporary array

## How to run

1. Download or clone this repository.
2. Open `index.html` in a browser (or serve the folder with a local static server).
3. Use the left navigation to switch between tasks.
4. Press **F12** (or right-click → **Inspect**) and open **Console** to view Task 0 and Task 1 console output.

No dependencies, installations, frameworks, database or localStorage are required.

## Publish with GitHub Pages

1. Create a GitHub repository and upload all files from this project to its root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Wait for the deployment and open the URL provided in GitHub Pages settings.
5. Submit the repository URL to Moodle. The assignment also requires you to defend your project during practice class.

You can alternatively deploy this folder as a static site on Netlify.
